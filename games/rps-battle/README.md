# 가위바위보 배틀

주먹, 보자기, 가위가 화면 안을 튕겨 다니다가 부딪히면 이긴 쪽으로 바뀌는 게임이에요.
마지막까지 남을 쪽에 코인을 걸고, 맞히면 배당만큼 코인을 받아요.

- 가위가 보자기에 닿으면 보자기가 가위로 바뀌어요.
- 보자기가 주먹에 닿으면 주먹이 보자기로 바뀌어요.
- 주먹이 가위에 닿으면 가위가 주먹으로 바뀌어요.
- 적게 넣은 쪽에 걸수록 배당이 커요. 코인은 PC에 저장되고, 다 잃으면 지원금을 받을 수 있어요.

## 설치

GitHub의 **Actions → 가위바위보 배틀 설치 파일 만들기** 에서 최신 실행의 `rps-battle-windows-setup` 을 내려받아 설치 파일을 실행하면 돼요.

## 개발

```
cd games/rps-battle
npm install
npm start      # 앱 실행
npm test       # 규칙 테스트
npm run dist:win
```
