# 가위바위보 배틀

바위, 보자기, 가위가 화면 안을 튕겨 다니다가 부딪히면 이긴 쪽으로 바뀌는 게임이에요.
새 판을 누르면 1, 2, 3 뒤에 이번 판에 각각 몇 마리씩 나오는지 공개되고,
그걸 보고 마지막까지 남을 쪽에 코인을 걸어요. 맞히면 배당만큼 코인을 받아요.

- 가위가 보자기에 닿으면 보자기가 가위로 바뀌어요.
- 보자기가 바위에 닿으면 바위가 보자기로 바뀌어요.
- 바위가 가위에 닿으면 가위가 바위로 바뀌어요.
- 한 판에 여러 곳에 나눠 걸 수 있어요. 안 걸고 구경만 할 수도 있어요.
- 혼자 할 때는 적게 나온 쪽에 걸수록 배당이 커요. 코인이 모자라면 은행에서 대출을 받을 수 있어요.

## 회원가입·로그인

앱을 켜면 로그인 화면이 먼저 나와요. 로그인/회원가입 탭을 고르거나 "로그인 없이 하기"로 바로 시작할 수 있어요.

아이디(한글·영어·숫자 2~10자)와 비밀번호(6자 이상)로 가입하면 코인과 전적이 Firebase(프로젝트 `gawi-bawi-bo`)의 Realtime Database에 저장돼서, 어느 컴퓨터에서 로그인해도 그대로예요. 로그인 없이 하면 코인은 그 컴퓨터에만 저장돼요.

Firebase 콘솔에서 Authentication의 이메일/비밀번호 로그인을 켜고, Realtime Database 규칙에 `database.rules.json` 내용을 넣어야 동작해요. 각자 자기 코인과 전적만 읽고 바꿀 수 있고, 아이디 이름은 못 바꿔요.

## 주식

왼쪽 메뉴의 📈 주식에서 게임 속 회사 40개의 주식을 코인으로 사고팔 수 있어요. 가격은 5초마다 바뀌고 모든 컴퓨터에서 똑같아요. 사고팔 때 수수료 1%가 붙어요. 차트는 5분, 30분, 3시간, 하루로 볼 수 있어요.

## 대출

지원금은 없어졌고, 대신 🏦 대출에서 최대 🪙 5,000까지 빌릴 수 있어요. 빚은 10분마다 3%씩 늘어나요(앱을 꺼 둬도). 코인도 주식도 없고 더 빌릴 수도 없으면 파산 신청으로 🪙 500부터 다시 시작할 수 있어요.

## 스킨 상점

왼쪽 메뉴의 🛍️ 상점에서 코인으로 손 모양 스킨을 사서 끼울 수 있어요. 스킨은 내 화면에서만 바뀌고, 산 스킨은 계정에 저장돼요.

| 스킨 | 가격 | 바위 / 보자기 / 가위 |
|---|---|---|
| 기본 손 | 무료 | ✊ / ✋ / ✌️ |
| 숫자 | 300 | 0 / 5 / 2 |
| 진짜 물건 | 600 | 🪨 / 📄 / ✂️ |
| 묵찌빠 | 1000 | 묵 / 빠 / 찌 |

## 친구랑 같이 하기 (다른 컴퓨터)

1. 한 명이 **방 만들기**를 누르면 5자리 방 코드가 나와요.
2. 다른 사람은 자기 컴퓨터에서 그 코드를 넣고 **참가**를 눌러요.
3. 방장이 **새 판 시작**을 누르면 모두 같은 판을 보고, 각자 자기 코인으로 걸거나 구경하기를 골라요. 뺏기 모드에서는 배틀이 시작되기 전까지 누가 어디에 얼마 걸었는지 안 보이고, 준비했는지만 보여요.
4. 첫 판 전에 방장이 베팅 방식을 골라요. **✖️ 몇 배 모드**는 혼자 할 때처럼 적게 나온 쪽일수록 배당이 커요. **💰 뺏기 모드**는 모두 건 코인을 한데 모아서, 이긴 쪽에 건 사람들이 건 만큼 비율대로 전부 나눠 가져요. 예를 들어 민수가 보자기에 100, 지우가 가위에 100을 걸고 가위가 이기면 지우가 200을 다 가져요. 이긴 쪽에 아무도 안 걸었으면 모두 돌려받아요.
5. 모두 고르면 방장이 배틀을 시작할 수 있어요.
6. 판이 끝나면 8초 뒤에 다음 판이 저절로 시작돼서, 나가기를 누르기 전까지 같은 방식으로 계속 해요. 베팅 방식은 첫 판 전에 한 번만 정해요.

방장 컴퓨터가 판을 돌리고 친구들에게 화면을 보내 줘요. 서로 연결해 줄 때만 PeerJS의 무료 연결 서버(0.peerjs.com)를 쓰고, 게임 내용은 컴퓨터끼리 직접 주고받아요. 인터넷만 되면 서로 다른 집에서도 할 수 있어요. 코인은 각자 자기 컴퓨터에 저장돼요.

## 설치

[최신 설치 파일 받기](https://github.com/ccho87hn-debug/claude/releases/latest/download/rps-battle-setup.exe) (GitHub 로그인 없이 바로 받아져요). 버전별 파일은 [Releases](https://github.com/ccho87hn-debug/claude/releases)에 있어요. 설치 파일을 실행하면 묻지 않고 바로 깔리고 게임이 켜져요.

## 개발

```
cd games/rps-battle
npm install
npm start      # 앱 실행
npm test       # 규칙 테스트
# 온라인 모드를 내 컴퓨터에서 시험할 때는 PeerJS 서버를 따로 띄우고
# 개발자 도구에서 localStorage.setItem("rpsBattle.peerServer", "localhost:9000")
npm run dist:win
```
