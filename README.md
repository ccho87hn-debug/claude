# 숙제 & 목표

오늘의 숙제와 이번 달 목표를 얼마나 달성했는지 보여주는 PC 앱입니다 (Windows / macOS, Electron).

## 기능

- **오늘의 숙제**: 과목별로 숙제를 추가하고 체크하면 완료율을 원형 그래프로 보여줍니다. 다른 날짜로 넘겨 볼 수도 있어요.
- **이번 달 목표**: 목표마다 기록 방식을 고를 수 있어요.
  - 횟수 세기: "책 4권 읽기"처럼 할 때마다 +1
  - 매일 체크: "줄넘기 20일"처럼 날마다 한 번 체크
  - 날짜 대비 진행 속도로 "순조로움 / 조금 늦음 / 분발 필요 / 달성"을 알려줍니다.
- **과목별 통계**: 과목별 완료율, 가장 밀린 과목, 최근 14일 그래프
- **연속 달성 & 배지**: 숙제를 전부 끝낸 날이 이어지면 연속 기록이 쌓이고 배지 10종을 받을 수 있어요.
- **바탕화면 위젯**: 항상 위에 떠 있는 작은 창에서 오늘 남은 숙제를 바로 체크하고, 목표 달성률과 연속 기록을 볼 수 있어요. 드래그해서 옮기면 위치를 기억해요.
- 어두운 화면이 기본이고, 밝은 화면으로 바꿀 수 있어요.

데이터는 내 컴퓨터의 앱 데이터 폴더(`data.json`)에 저장됩니다.

## 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm start
```

## 설치 파일 만들기

```bash
npm run dist:win   # Windows 설치 파일 (.exe) — Windows에서 실행
npm run dist:mac   # macOS 설치 파일 (.dmg) — Mac에서 실행
```

만들어진 파일은 `dist/` 폴더에 생깁니다.
