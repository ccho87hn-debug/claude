# 숙제 & 목표

오늘의 숙제와 이번 달 목표를 얼마나 달성했는지 보여주는 PC 앱입니다 (Windows / macOS, Electron).

## 기능

- **오늘의 숙제**: 과목별로 숙제를 추가하고 체크하면 완료율을 원형 그래프로 보여줍니다. 다른 날짜로 넘겨 볼 수도 있어요.
- **이번 달 목표**: 목표마다 기록 방식을 고를 수 있어요.
  - 횟수 세기: "책 4권 읽기"처럼 할 때마다 +1
  - 매일 체크: "줄넘기 20일"처럼 날마다 한 번 체크
  - 날짜 대비 진행 속도로 "순조로움 / 조금 늦음 / 분발 필요 / 달성"을 알려줍니다.
- **이번 주**: 월~일 7칸 보드로 그 주 숙제를 한눈에 보고 바로 체크해요.
  - **주의할 것**: 시험·준비물·마감을 날짜와 함께 적어두면 D-day로 표시되고, 7일 안에 다가오면 오늘 화면과 위젯에 알려줘요.
  - **주간 메모 (편집 / 보기)**: 편집 탭에서 쓰고 보기 탭에서 정리된 모양으로 읽어요. `# 제목`, `- 목록`, `! 중요`, `[ ] 할 일`, `[x] 한 일`을 쓸 수 있어요.
- **주간 계획표 (엑셀 스타일)**: 행은 과목, 열은 월~일입니다. 칸에 숙제를 적으면 그날 숙제가 돼요.
  - 한 칸에 여러 개는 `;`로 구분하고, Enter는 아래 칸, Tab은 오른쪽 칸, 방향키로 이동, Esc는 되돌리기예요.
  - 위쪽 fx 입력줄에서도 고칠 수 있어요. 맨 아래 "주의할 것" 행은 주의할 것 목록과 연결돼요.
  - "+ 과목 행"으로 과목을 추가하고, "지난주 계획 불러오기"로 지난주 내용을 그대로 가져올 수 있어요.
- **관리의 날**: 요일을 하나 정하면 그날 오늘 화면과 위젯에 알림이 뜨고, 계획표가 다음 주로 열려요.
- **고치기**: 숙제·목표·주의할 것 옆의 ✎ 버튼으로 내용, 과목, 날짜, 목표 수를 고칠 수 있어요 (Enter 저장, Esc 취소).
- **과목별 통계**: 과목별 완료율, 가장 밀린 과목, 최근 14일 그래프
- **연속 달성 & 배지**: 숙제를 전부 끝낸 날이 이어지면 연속 기록이 쌓이고 배지 21종을 받을 수 있어요.
- **바탕화면 위젯**: 항상 위에 떠 있는 작은 창에서 오늘 남은 숙제를 바로 체크하고, 목표 달성률과 연속 기록을 볼 수 있어요. 드래그해서 옮기면 위치를 기억해요.
- 어두운 화면이 기본이고, 밝은 화면으로 바꿀 수 있어요.
- **화면 크기에 맞춤**: 창을 키우거나 전체 화면(F11)으로 하면 글자와 버튼이 같이 커지고, 넓은 화면에서는 주의할 것이 오른쪽 칸으로 옮겨가요. 좁은 창에서는 왼쪽 메뉴가 아이콘만 남아요. `Ctrl +` / `Ctrl -` / `Ctrl 0`이나 왼쪽 아래 "화면 크기" 버튼으로 직접 조절할 수 있고, 창 크기와 위치는 다음에 켤 때도 그대로예요.

데이터는 내 컴퓨터의 앱 데이터 폴더(`data.json`)에 저장됩니다.

## Windows 11에 설치하기

1. GitHub 저장소의 **Actions** 탭 → **Windows 설치 파일 만들기** → 가장 최근의 초록색 체크 실행을 엽니다.
2. 아래쪽 **Artifacts**에서 `homework-goals-windows-setup`을 내려받아 압축을 풉니다.
3. `homework-goals-setup-1.3.1.exe`를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누르세요. 코드 서명이 없는 앱이라 나오는 안내입니다.
4. 설치가 끝나면 시작 메뉴에서 **숙제 & 목표**를 실행합니다.

## 개발용으로 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm start
```

## 설치 파일 만들기

```bash
npm run dist:win   # Windows 설치 파일 (.exe) — Windows에서 실행
npm run dist:mac   # macOS 설치 파일 (.dmg) — Mac에서 실행
```

만들어진 파일은 `dist/` 폴더에 생깁니다.
